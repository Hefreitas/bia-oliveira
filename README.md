# Site da Bia Oliveira

Site pessoal da Bia Oliveira — criadora de conteúdo, social media e biomédica esteta (CRBM 22661).

Publicado com GitHub Pages: https://hefreitas.github.io/bia-oliveira/

## Como editar
- **Textos:** abra `index.html`, clique no lápis (Edit) e altere o texto entre as tags.
- **Cores e fontes:** ficam no topo do `style.css` (variáveis `--vinho`, `--vermelho` etc.).
- **Fotos:** substitua o arquivo em `img/` mantendo o mesmo nome (formato .webp).
- **Link do WhatsApp:** procure por `https://w.app/mya6be` no `index.html`.

Depois de salvar (commit), o site atualiza sozinho em 1–2 minutos.
